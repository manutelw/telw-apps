The IELTS preview Worker is separate from the shared production Worker. Deploy the `feat/ielts-isolated-preview` branch with `npx wrangler deploy --config wrangler.ielts-preview.jsonc`. It uses the dedicated `telw-ielts-preview` D1 database. Set its own authentication and mail secrets before testing. The preview is for testing only; approved question banks and end-to-end verification are still required.
