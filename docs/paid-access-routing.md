# Paid access routing rule

Public paid ClarionPrep products use direct self-purchase.

- FIIB visitors follow the same paid checkout flow as other private buyers.
- Paid PI Practice and GD Practice do not require trainer or FIIB approval before checkout.
- Paid-product access requests must not send approval, permission, or payment-link request emails to `@fiib.edu.in` addresses.
- Trainer-controlled access remains available only for deliberately restricted institutional tools and assignments (for example trainer-assigned labs), not as a prerequisite for a public paid purchase.
