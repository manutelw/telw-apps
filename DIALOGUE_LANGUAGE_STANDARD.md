# TELW / ClarionPrep Dialogue Language Standard

## Global rule: natural spoken contractions

For learner-facing spoken dialogue across TELW and ClarionPrep, use natural contractions by default whenever a fluent speaker would normally use them.

Examples include:

- `I am` → `I’m`
- `we are` → `we’re`
- `you are` → `you’re`
- `it is` → `it’s`
- `I will` → `I’ll`
- `do not` → `don’t`
- `does not` → `doesn’t`
- `did not` → `didn’t`
- `is not` → `isn’t`
- `are not` → `aren’t`
- `cannot` → `can’t`
- `will not` → `won’t`
- `would not` → `wouldn’t`
- `should not` → `shouldn’t`

Use positive `have` contractions only when they sound natural as auxiliaries, for example `I’ve already...`, `we’ve been...`, or `they’ve just...`. Do not mechanically contract lexical `have` where the result sounds unnatural.

## Do not force a contraction

Keep the full form when it is deliberately needed for:

- emphasis;
- contrast;
- a very formal register;
- explicit grammar teaching;
- pronunciation or form-focused practice;
- any phrase where a contraction would be incorrect or unnatural.

For example, `how was` stays `how was`; it is not replaced by `how’s`.

## Display and audio must match

If dialogue is contracted on screen, the spoken audio must use the same wording. Speaker labels must remain unchanged and must not be spoken aloud unless a lesson explicitly requires that.

## Scope

This is the default standard for current and future learner-facing TELW / ClarionPrep conversational dialogue, including ORACY dialogue. It does not silently rewrite protected source material, quoted material, assessment wording, or teaching examples whose full forms are pedagogically intentional.
