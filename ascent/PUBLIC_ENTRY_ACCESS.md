# Public entry access

The ClarionPrep public landing page keeps the PCL and Live Mock Interview service entries visible but non-clickable for ordinary visitors.

Those two public entries are enabled only when the same browser has a current ASCENT administrator session created through the Admin Portal (`ascent_admin_master_session` or an ADMIN `ascent_trainer_session`).

This is a public-navigation gate only. It does not reconnect Live Mock learner identity, entitlements, sessions, or data to ASCENT, and it does not modify ASCENT Play.
